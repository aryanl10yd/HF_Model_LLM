# HuggingFace Model LLM Project

I created this project as a way to test out the limits and use cases of HuggingFace Models

## Overview

I made this project in order to expand my understanding of AI and ML by working with active LLM Models from a well known AI model site for programmers known as HuggingFace

## Features

- Utilized many new concepts about AI and ML, including transformers and pipelines in order to interact, communicate with, and gain data from the LLM Models i was using
- Terminal based output only

## Technologies

- Llama LLM Model (HuggingFace)
- Python (Transformers, AutoModel, Pytorch, Pipeline, LlamaModel, Requests)
